# Chrwme Trading Bible — 共享术语词典

> 中文技术校订稿为主，英文稿用于核对原术语。本词典只定义会改变结构确认、情景分流、执行位置或风险判断的概念。技术校订版新增或收紧的定义不直接归因于原作者。

| 术语 | 本资料中的工作定义 | 关键区别 |
|---|---|---|
| Relevant / Meaningful Swing | 与当前趋势和情景相关、可承担结构判断责任的关键摆动点 | 不是任何局部高低点；资料没有机械阈值 |
| Displacement | 有方向性、穿越相关 Swing 并产生清晰结构结果的推动 | 不是任意大 K 线或瞬时影线 |
| CHoCH | 对原趋势方向首次形成的、有意义的反向 Swing 突破 | 是初始转变候选，不等于完整 MSS 或入场许可 |
| MSS | 由明显位移和上下文强化的结构转移确认 | 更强调确认质量，不与 CHoCH 完全互换 |
| BOS | 新方向已经建立后的顺向关键 Swing 突破 | 表示延续，不表示首次反转 |
| Potential Liquidity Pool | 明显高低点附近可能聚集止损、突破单等挂单的候选区域 | 是解释模型，不证明具体机构身份或意图 |
| Liquidity Sweep | 价格短暂穿越关键高低点后回到原区域的事件 | 是情景起点；后续仍可反转、盘整或延续 |
| PD Array | 特定背景下用于评估回撤位置的一类结构，如 OB、FVG、Breaker | 不是独立买卖信号 |
| Order Block | 有意义位移前最后一根或一组反向 K 线，且推动产生结构结果 | 不限于绝对顶底，也不是任意反向 K 线 |
| Breaker Block | 原 OB 明确失效、被反向位移穿越并从另一侧回测后的角色反转区 | 不是普通突破回测区 |
| Fair Value Gap | Candle 1 与 Candle 3 相对侧影线不重叠的三 K 线失衡 | 不是“没有交易”，也不保证回补 |
| 作者模型中的 Accumulation / Distribution | 作者五阶段多空模型里的扩张或建仓标签 | 不等于 Wyckoff 交易区间 |
| Wyckoff Accumulation TR | 下跌后供给被吸收、为潜在 Markup 做准备的区间 | Spring 可选；不是作者模型的多头建仓标签 |
| Wyckoff Distribution TR | 上涨后供给逐渐压过需求、为潜在 Markdown 做准备的区间 | UTAD 可选；不能复制吸筹事件名称 |
| Reaccumulation / Redistribution | Markup 后更高位置、或 Markdown 后更低位置形成的新中继区间 | 不是原始吸筹/派发区间的后半程 |
| Working Range | 用 PDH/PDL 暂时组织日内 Bias、目标与失效的上下文区间 | 是可迁移假设，不是硬边界 |
| Acceptance | 价格在参考位外持续交易，并由后续结构和 Price Delivery 支持 | 不是单次触碰或影线；资料未量化统一阈值 |
| PDH / PDL Reversal | 扫过前日边界、重新站回/跌回，并由同向位移/MSS强化的对称反转情景 | 不是刺穿边界就反转 |
| Structural Invalidation | 交易 Thesis 在结构上不再成立的位置 | 不是为凑 R:R 任意选择的止损距离 |
| Expectancy | 胜率、平均盈利、平均亏损和成本共同决定的长期每笔期望 | 不是单笔 R:R，也不是单次盈亏 |

## 使用原则

- 遇到术语冲突时，先写出实际价格行为，再附本词典标签。
- 任何“明显”“持续”“相关”等未量化条件，都必须由用户的品种、周期或测试规则操作化。
- 不把解释性术语升级为可从图表直接证明的机构事实。
